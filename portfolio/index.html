/RECENT FIXES 7 entries
fix Booking data was leaking across user accounts after logout/login — traced to a shared, unfiltered array overwriting per-user state on every page load.
fix Dashboard stats stayed frozen on the previous user's numbers after logout instead of resetting — the update function was silently returning early for logged-out state.
fix Login sessions didn't survive a page refresh unless "Remember Me" was checked — now persists by default, matching every other auth path in the app.
perf Load-tested the live Realtime Database with 50 concurrent writes to a throwaway path — 100% success, zero write conflicts, cleaned up automatically after.
sec Database was fully open to public read/write. Replaced with schema-validated rules — any write must match the real data shape, with zero changes needed to the login flow.
fix "Forgot password" always showed "email sent" — but no email service was ever wired up. Rebuilt it into a real, working in-app reset instead of a message that went nowhere.
fix Shared links on WhatsApp/LinkedIn showed a blurry page screenshot instead of a real preview — added proper Open Graph tags and a designed share image.
